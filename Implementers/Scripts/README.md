### Scripts

To distinguish between implementations based on the rooting and framework layers, we will refer to implementations (e.g., LSPosed) based on the rooting layer as modules, 
implementations (e.g., QQ Repeater) based on framework layers as plugins, and scripts (e.g., scripts written in Java executed by QQ Repeater) written based on plugins as scripts. 

Since scripts are typically developed based on specific plugins, no scripts are stored here. 

---

### 脚本

为区别基于 root 层和框架层的实现，我们将基于 root 层的实现（如 LSPosed）称为模块，
基于框架层的实现（如 QQ 复读机）称为插件，将基于插件编写的脚本（如 QQ 复读机执行的 Java 脚本）称为脚本。

由于脚本通常基于特定插件开发，此处不存储任何脚本。
