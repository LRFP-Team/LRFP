### Plugins

To distinguish between implementations based on the rooting and framework layers, we will refer to implementations (e.g., LSPosed) based on the rooting layer as modules, 
implementations (e.g., QQ Repeater) based on framework layers as plugins, and scripts (e.g., scripts written in Java executed by QQ Repeater) written based on plugins as scripts. 

Since each framework layer manager has a download tab and the plugin repository is already quite mature, only some plugins for bypassing or archived plugins are stored here. 
Please download and install them from the plugin repository or Telegram channel if necessary. 

- Core Patch: [https://modules.lsposed.org/module/com.coderstory.toolkit/](https://modules.lsposed.org/module/com.coderstory.toolkit/)
- FuseFixer: [https://github.com/5ec1cff/FuseFixer](https://github.com/5ec1cff/FuseFixer)
- HMA (closed-source): [https://t.me/HideMyApplist](https://t.me/HideMyApplist)
- HMAL: [https://github.com/pumPCin/HMAL](https://github.com/pumPCin/HMAL)
- PixelXpert (archived, recommend ``canary-487`` to reduce bugs): [https://github.com/siavash79/PixelXpert](https://github.com/siavash79/PixelXpert)

### 插件

为区别基于 root 层和框架层的实现，我们将基于 root 层的实现（如 LSPosed）称为模块，
基于框架层的实现（如 QQ 复读机）称为插件，将基于插件编写的脚本（如 QQ 复读机执行的 Java 脚本）称为脚本。

由于各框架层管理器均有下载选项卡且插件仓库已十分成熟，此处仅存储一些用于过检或已停更的插件。
如有需要，请从插件仓库或电报频道下载安装。

- 核心破解：[https://modules.lsposed.org/module/com.coderstory.toolkit/](https://modules.lsposed.org/module/com.coderstory.toolkit/)
- FuseFixer：[https://github.com/5ec1cff/FuseFixer](https://github.com/5ec1cff/FuseFixer)
- HMA（闭源）：[https://t.me/HideMyApplist](https://t.me/HideMyApplist)
- HMAL：[https://github.com/pumPCin/HMAL](https://github.com/pumPCin/HMAL)
- PixelXpert（已停更，推荐使用 ``canary-487`` 版本以减少 bugs）：[https://github.com/siavash79/PixelXpert](https://github.com/siavash79/PixelXpert)
